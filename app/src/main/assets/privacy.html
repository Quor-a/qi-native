隐私政策

1. 我们收集什么

本应用不主动收集您的个人信息。以下数据仅在您本机产生并存储：

  • 您配置的模型接口地址与 API Key（保存在本机 SharedPreferences）；
  • 聊天记录、灵魂卡设定、语音球偏好（保存在本机文件）；
  • 应用运行所需的必要权限（麦克风、悬浮窗、通知、存储等）。

2. 数据发给谁

您与 AI 的对话内容会按您的配置发送给您指定的第三方大模型接口。我们不会将这些内容转发给其他任何第三方。

3. 云端备份

应用不默认开启任何云端同步。如您使用「导出 / 导入」功能，数据文件由您自行保管。

4. 权限用途

麦克风用于语音输入与语音聊天；悬浮窗用于全局语音球；通知用于语音球前台服务提示；存储用于导出聊天记录。您可随时在系统设置中撤回授权。

5. 您的权利

您可随时在「存储与备份」中清除本地缓存与导出数据，卸载应用将一并删除本机数据。
