「栖」（qi）以 Apache License 2.0 开源，源码发布于 Gitee（仓库见应用内说明）。本项目的完整许可证文本见仓库根目录的 LICENSE 文件。

「栖」派生自 ZorvAI / QuroAI 项目，遵循其原有开源许可；在此致谢上游项目与所有贡献者。本项目在派生基础上进行了去品牌化与功能重构（多会话历史、AI 发送文件 / 应用内自写预览、工具子系统、权限声明等）。

核心依赖（遵循各自许可协议）

核心依赖

  • Android · 应用平台（Apache License 2.0）
  • Kotlin · 开发语言（Apache License 2.0）

说明

本应用未引入任何第三方闭源 SDK 进行数据采集。所有网络请求仅发往您在「模型配置」中填写的接口地址。
