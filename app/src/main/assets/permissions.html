权限使用声明

「栖」是一款本地优先的 AI 陪伴应用。为支持可扩展的「工具」子系统（让 AI 在您授权后调用设备能力），应用声明了较广泛的权限集合；但绝大多数危险权限默认不授予，仅在您实际触发对应功能时才请求，且被拒绝时相关功能会返回友好提示而不会崩溃。

必要应用运行基础权限

  • INTERNET（网络）：连接您在「模型配置」中填写的 AI 接口、加载在线资源。无此权限应用无法对话。
  • RECORD_AUDIO（麦克风）：语音输入、语音通话与语音球悬浮窗。
  • FOREGROUND_SERVICE 及其子类型（microphone / data_sync / media_playback）：后台语音识别、语音球常驻。
  • POST_NOTIFICATIONS：Android 13+ 显示语音球与提醒通知。
  • SYSTEM_ALERT_WINDOW（悬浮窗）：语音球悬浮窗，需在系统设置中手动授予。
  • RECEIVE_BOOT_COMPLETED：开机后恢复提醒与语音球（需您主动启用）。

按需工具子系统权限（核心亮点）

内置「工具」子系统使 AI 可在您授权后调用设备能力。以下危险权限仅在对应工具被实际调用时才会请求：

  • 短信：SEND_SMS / READ_SMS / RECEIVE_SMS / RECEIVE_MMS / SEND_MMS —— 工具「发送 / 读取短信」时请求。
  • 电话：CALL_PHONE / READ_PHONE_STATE / READ_CALL_LOG / WRITE_CALL_LOG / READ_PHONE_NUMBERS —— 工具「拨打电话 / 读取通话记录」时请求。
  • 通讯录：READ_CONTACTS / WRITE_CONTACTS / GET_ACCOUNTS —— 工具「查询联系人」时请求。
  • 日历：READ_CALENDAR / WRITE_CALENDAR —— 工具「读写日历事件」时请求。
  • 定位：ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION / ACCESS_BACKGROUND_LOCATION —— 工具「获取位置 / 天气」时请求。
  • 相机：CAMERA —— 工具「拍照 / 扫码」时请求。
  • 存储：READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO，以及旧版 READ/WRITE_EXTERNAL_STORAGE —— 工具「读写本地文件」时请求。
  • 其他辅助：VIBRATE（振动反馈）、ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE（网络状态）、SET_ALARM / SCHEDULE_EXACT_ALARM（设置闹钟 / 提醒）。

特殊系统级权限（需手动在设置授予）

  • PACKAGE_USAGE_STATS：工具「查询应用使用情况」时请求（UsageStatsManager）。
  • MANAGE_EXTERNAL_STORAGE：工具「访问全部文件」时请求（Android 11+）。
  • WRITE_SETTINGS：工具「修改系统设置」时请求。
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS：引导关闭电池优化以保证后台语音连续。
  • ACCESS_NOTIFICATION_POLICY：工具「勿扰模式控制」时请求。

占位外部集成权限（对应库未引入时零影响）

  • Shizuku（moe.shizuku.manager.permission.API / API_V23）：若您安装 Shizuku 并授权，可让工具以更高权限执行 shell 命令。
  • ACI（ai.aci.permission.CALL / DISCOVER）：外部 AI 命令接口占位声明。

系统 / 包可见性

  • QUERY_ALL_PACKAGES：Android 11+ 查询已安装应用，用于工具与内置浏览器分流。
  • WAKE_LOCK / CHANGE_WIFI_STATE / NFC 等：系统能力占位声明。

数据处理原则

  • 本地优先：聊天记录、灵魂卡设定、AI 发送的文件默认仅保存在您本机存储中。
  • 网络最小化：所有 HTTP / SSE 请求仅发往您在「模型配置」中填写的接口地址；应用未内置任何第三方数据采集 SDK。
  • 按需授权：危险权限仅在对应工具被实际调用时请求，您可随时在系统设置中撤回。
